### Decisiones del script para Windows
- **PowerShell y no `.bat`:** permite revisar los puertos, esperar a la API y detener el backend en un bloque
  `finally`, igual que el `trap` de `levantar.sh`.
- **Vite se llama con `node` y no con `npm run dev`:** `npm` es un `.cmd`, y al pulsar Ctrl+C Windows preguntaría
  si se termina el trabajo por lotes.
- **`taskkill /T`** detiene el árbol de procesos: `mvnw.cmd` lanza Maven y Maven lanza la JVM. Cumple la misma
  función que `setsid` en Linux.
- **UTF-8 con BOM:** sin la BOM, Windows PowerShell 5.1 lee el archivo como ANSI y daña las tildes de los mensajes.
- **`-ExecutionPolicy Bypass`** en la línea de uso: así no hay que cambiar la política del equipo.
